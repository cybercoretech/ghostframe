03 / Privacy and control

You choose what leaves the editor.

Export metadata controls

Exports strip GPS by default. Choose KEEP ALL, ANONYMOUS, or STRIP ALL. Captions and tags are embedded in XMP, and a sidecar can preserve the edit recipe.

Credentials stay local

The PhotoPrism app password is stored in an owner-only local configuration file and restored automatically on launch.

No cloud AI required

PhotoPrism can use local image labeling or an optional local vision service. Ghostframe itself does not send photos to a cloud AI provider.

Self-hosted, not end-to-end encrypted

PhotoPrism needs readable images to index them. Use a trusted host and network, HTTPS across untrusted networks, and independent backups.

04 / Get started

Build it on your Linux desktop.

Ghostframe is currently a desktop MVP distributed from source. It needs a reachable PhotoPrism server and a read-scoped PhotoPrism app password.

01

Install the build requirements

Linux, Qt 6.5+, qmake6, a C++20 compiler, make, libvips 8.15+ with C++ bindings, and Cybermeta 0.2+ for metadata features.

02

Connect your PhotoPrism library

Use a PhotoPrism app password with read access. The local Compose setup binds to loopback and indexes originals read-only.

03

Launch and browse

Enter the server URL and password once. Ghostframe verifies and remembers the connection for your next session.

Build from source / Linux

git clone https://github.com/cybercoretech/ghostframe.git && cd ghostframe && qmake6 ghostframe.pro && make -j"$(nproc)" && ./ghostframe

Copy the command, then run it in your terminal. See the README for dependencies and PhotoPrism setup.
